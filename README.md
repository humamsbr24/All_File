# HUMAM Pro v6

منصة HUMAM — المستمسكات (Documents) والبيانات (Data) وأدوات PDF في تطبيق واحد مشفّر.

## الرفع على GitHub Pages
1. ارفع كل ملفات هذا المجلد إلى جذر المستودع (index.html مع الأيقونات و manifest.webmanifest و sw.js).
2. من Settings ← Pages اختر الفرع `main` والمجلد `/ (root)` ثم احفظ.
3. افتح الرابط من Safari على الآيفون ← مشاركة ← «إضافة إلى الشاشة الرئيسية».
   على ويندوز افتحه في Edge أو Chrome واضغط زر «تثبيت».

## مزايا
- شاشة دخول جديدة تتكيّف مع الآيفون والكمبيوتر، وضع فاتح/داكن.
- التعرّف التلقائي على القسم من كلمة المرور، وتنبيه زر الأحرف الكبيرة.
- قفل تلقائي عند الخمول، واختصار Ctrl+Shift+L للقفل وCtrl+Shift+D لتبديل الوضع.
- قائمة عائمة داخل التطبيق: تبديل الوضع، ملء الشاشة، قفل.
- أيقونات خطية موحّدة بدل الرموز التعبيرية في كل الأقسام.
- يعمل بدون إنترنت بعد أول فتح (عند رفعه على GitHub Pages).
- روابط مباشرة: ‎#doc‎ و ‎#data‎ و ‎#pdf‎ لاختيار القسم.
